# `scripts/` — что здесь лежит

В корне папки остался один рабочий скрипт, всё остальное — архив разовых
миграций.

## Рабочее

| Файл | Что делает |
| --- | --- |
| `admin-migrate.mjs` | Создаёт таблицы и bucket для админки. |

Запуск:

```powershell
$env:PGURL="postgresql://..."; node scripts/admin-migrate.mjs
```

`PGURL` — строка подключения к Postgres (Supabase → Project Settings →
Database → Connection string → URI). Больше ничего не требуется: скрипт
идемпотентный (`create table if not exists`).

## Архив: `_archive/`

Эти скрипты **уже отработали** и запускать их повторно нельзя — они не
идемпотентны и перезаписывают данные:

| Файл | Что делал | Почему опасен повтор |
| --- | --- | --- |
| `recreate-reviews.mjs` | `DROP TABLE reviews` и создание заново | **Уничтожит все отзывы** |
| `migrate-programs.js` | Перезапись `programs` статическими дефолтами | Затрёт правки из админки |
| `gallery-rewrite.js` | Замена галереи на фиксированный список | Затрёт правки из админки |
| `dedupe-images.js` | Раскладка фото по секциям без дублей | Затрёт текущие `src` |
| `gallery-spans-fix.js` | Правка `span` у фото галереи | Разово |
| `program-photo-positions.js` | Позиции фото программ | Разово |
| `hero-rotation-seed.js` | Заполнение `hero.images` | Идемпотентен, но разовый |
| `insert-hooks.mjs` | Вставка `useContent()` в компоненты | Разово, якоря уже изменены |
| `transform-content.mjs` | Перевод секций на `useContent()` | Разово |
| `inspect-programs.mjs` | Диагностика схемы `programs` | Безопасен, но больше не нужен |
| `programs-category-migrate.sql` | Перенос категории в `features->>'category'` | Разово |

### Общая беда этих скриптов

Они читают `.env.local` **по абсолютному пути** `D:\sfera\.env.local` и
подключают `@supabase/supabase-js` **по абсолютному пути**
`D:\sfera\node_modules\...`. На другой машине или в другом каталоге они не
запустятся. Чинить это не стал: скрипты одноразовые, а «починенный» скрипт
легче случайно запустить повторно.

Если понадобится повторить что-то из этого списка — сначала прочитайте
файл целиком и убедитесь, что понимаете, какие данные он перезапишет.
